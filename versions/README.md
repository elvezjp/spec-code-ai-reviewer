# versions ディレクトリについて

## 概要

このディレクトリには、`spec-code-ai-reviewer` の各バージョンのスナップショットを保存します。
UI左上のバージョン切替ボタンから、過去バージョンのUI/挙動に切り替えてテストすることができます。

## 更新履歴

### v0.9.5 (2026-03-26)
- **フロントエンド・バックエンドのバージョン不一致検知**（#81）: 起動時にバックエンドのバージョンを確認し、フロントエンドと一致しない場合に画面上部に警告バナーを表示。`GET /api/health` エンドポイントを追加
- **全API関数のHTTPレスポンスチェック追加**（#79）: `fetchHeadings()` をはじめとする全API関数に `response.ok` チェックを追加し、非2xxレスポンス（405, 500等）を正しく検知するよう修正
- **assertResponseOkヘルパー導入**: 共通のレスポンスチェック関数で全API関数のエラーハンドリングを統一
- **エラー判定の堅牢化**: `useSplitSettings.ts` のエラー判定に `result.error` チェックを追加

### v0.9.4 (2026-03-26)
- **サマリーモードオプション**（#71）: 分割プレビュー設定に `summaryMode`（ルールベース/AI）と `summaryMaxChars`（サマリー最大文字数）を追加
- **最大サブスプリット数UI化**: 環境変数 `MD2MAP_MAX_SUBSECTIONS` を廃止し、フロントエンドUIから直接指定可能に
- **分割モード連動**: 分割モード変更時にサマリーモードが自動連動（AI→AIサマリー、見出し/NLP→ルールベース）
- **分割プレビューからMAP.json・INDEX.mdダウンロード**（#73）: レビュー実行前の分割プレビュー画面で設計書・コードのMAP.json / INDEX.mdを個別ダウンロード可能に
- **分割プレビュー再実行機能**（#76）: プレビュー実行後、ボタンが「プレビュー再実行」に変化し、1クリックで結果クリア＋再実行が可能に。完了メッセージも表示

### v0.9.3 (2026-03-24)
- **事前除外指定機能**（#68）: 分割前にセクション単位で「事前除外指定」を行い、不要なセクションを分割処理から完全に除外可能に
- **事前指定パネル**: 「事前重要指定」パネルを「事前指定」に改名し、事前重要指定・事前除外指定の排他制御を追加
- **md2map v0.3.2対応**: `section_overrides` の `skip` 機能を利用した事前除外処理

### v0.9.2 (2026-03-20)
- **事前重要指定機能**（#66）: 分割前にセクション単位で「事前重要指定」を行い、事前重要指定セクションと通常セクションで異なる分割設定（分割モード、見出しレベル、AI注意事項）を適用可能に
- **見出し一覧取得API**: `POST /api/split/headings` エンドポイント追加。H2見出し一覧を取得し、事前重要指定UIで使用
- **md2map v0.3.1対応**: `extract_headings()` / `section_overrides` 機能を利用したセクション単位の分割設定切り替え

### v0.9.1 (2026-03-13)
- **グループレビュー個別結果のZIP同梱**: 分割レビュー時のZIPダウンロードに各グループのレビュー結果（`split/review-result-{groupId}.md`）を含める（#60）
- **セクション除外機能**: 分割プレビューの設計書パーツ一覧に「除外」チェックボックスを追加。チェックしたセクションを構造マッチング・グループレビューの対象から除外できる（#54）
- **AIサブスプリット注意事項指定**: AIモード分割時に「分割時の注意事項（AIへの指示・任意）」テキストエリアを追加。入力内容が AIサブスプリットプロンプトに追記される（#55）

# v0.8.2: 行番号ハルシネーション修正 & レビューモード表示

作成日: 2026-02-21

関連issue: #43, #44

## 背景/問題

### issue #43: 行番号ハルシネーション
LLMが出力するコード行番号が実際のファイル行数を大幅に超える（実測で約2倍）ハルシネーションが発生している。LLMはコードの総行数を知らないため、コード内の行番号（埋め込み数字）と入力メッセージ内の位置情報を混同している可能性がある。

### issue #44: レビューモード未表示
レビュー結果のREADMEおよび結果表示画面に、どのモード（一括/分割）でレビューが実行されたかが記載されない。また分割レビュー時のグループ分け結果も確認できない。

## ゴール

- 標準レビュー・分割レビューそれぞれにおいて、LLMが正しい行番号を参照できるようにする
- 標準レビューのユーザープロンプトにコードファイルの総行数を付記する
- レビュー結果のREADMEと画面にレビューモード（一括/分割）を表示する
- 分割レビュー時はグループ分け結果もREADMEに出力する

## 非ゴール

- `add-line-numbers` の仕様変更
- code2map フラグメントへの行番号付与
- グループレビューのユーザープロンプトへの総行数付記

## 作業方針

`versions/v0.8.1` をそのまま `versions/v0.8.2` としてコピーし、以下の変更を `v0.8.2` に対して行う。`spec.md` も含めてすべて `v0.8.2` 配下で修正する。

issue #43 の対応をすべて完了させてから、issue #44 の対応を行う。

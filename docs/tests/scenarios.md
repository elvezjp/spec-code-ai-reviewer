# シナリオテスト — spec-code-ai-reviewer

## 指示

以下のシナリオを順番に実行し、試験項目ごとに OK / NG を判定してください。

- 各シナリオの手順に従い、ブラウザ上で操作を行い、試験項目の判定基準で合否を判断すること
- NG の場合は、エラー内容やスクリーンショットの所見を備考に記載すること
- 全シナリオ完了後、末尾の「結果報告フォーマット」に従い、マークダウン形式で結果を出力すること
- ファイル名は `YYYYMMDD-HHMM-scenario.md`（例: `20260228-1430-scenario.md`）とすること
- **人間の操作が必要な場合**（ファイル選択ダイアログ、ブラウザ外の確認など）は、無理に進めず、ユーザーに操作内容を伝えて完了を待つこと

## 前提条件

- バックエンドサーバーが起動済み（`http://localhost:8000`）
- フロントエンド開発サーバーが起動済み（`http://localhost:5173`）
- テスト用の設計書（Excel `.xlsx`）とプログラムファイル（Java `.java`）を用意すること

## テスト準備: テストファイルの選択

テスト開始前に、ユーザーにテスト用ファイルを選択してもらいます。
**この手順はファイル選択ダイアログの操作が必要なため、ユーザーが手動で行います。**

### 手順

1. ブラウザで `http://localhost:5173` にアクセスする
2. 「設計書 (Excel)」セクションの「ファイルを選択」ボタンをクリックし、テスト用の Excel ファイル（`.xlsx`）を選択する
3. 「プログラム」セクションの「ファイルを選択」ボタンをクリックし、テスト用の Java ファイル（`.java`）を選択する
4. 両方のファイル名が画面に表示されていることを確認する

> **テスト実行AIへの指示**: この手順が完了するまで待機してください。ユーザーがファイル選択を完了したことを確認してから、シナリオ1 に進んでください。

## レビュー実行の大まかな流れ

このアプリは「設計書-Javaプログラム突合 AIレビュアー」です。設計書とプログラムをAIがレビューします。
テストを実行する際は、以下の流れを理解した上で各シナリオに取り組んでください。

1. **設計書の変換**: 「設計書 (Excel)」セクションの「ファイルを選択」ボタンで Excel ファイルを選択 → ツールドロップダウンで `excel2md` を選択 → 「マークダウンに変換」ボタンを押下
2. **プログラムの変換**: 「プログラム」セクションの「ファイルを選択」ボタンで Java ファイルを選択 → 「add-line-numbersで変換」ボタンを押下
3. **分割設定（任意）**: 「分割設定」セクションで「分割」ラジオボタンを選択 → 分割オプションで「AI（推奨）」を選択 → 「分割プレビュー」ボタンを押下
4. **レビュー実行**: 画面下部の「レビュー実行」ボタンを押下 → 実行中画面に遷移
5. **実行中のエラー対応**: エラーが表示されたら「リトライ」ボタンで再試行、同じエラーが繰り返されるなら「スキップ」ボタンで次へ進む
6. **結果確認・ダウンロード**: 結果画面で簡易判定・詳細レポートを確認 → 「一式ダウンロード（ZIP）」ボタンでデータを保存

## シナリオ2: 設計書の変換

### 手順

> テスト準備で Excel ファイルが選択済みであること。

1. 設計書のファイル名が表示されていることを確認する
2. 各ファイルの「ツール」ドロップダウンで変換ツールの選択肢を確認する
3. 「マークダウンに変換」ボタン（青色）をクリックする
4. 変換完了後、「変換結果をプレビュー」をクリックして変換内容を確認する

### 試験項目

| # | 試験項目 | 実行 | 判定基準 |
|---|---------|:----:|---------|
| 2-1 | Excel ファイルが選択されている | AI | テスト準備で選択した Excel ファイルのファイル名が「設計書 (Excel)」セクションに表示されている |
| 2-2 | ツール選択ドロップダウンにツール一覧が表示される | AI | 各ファイルの「ツール」ドロップダウンに `MarkItDown`、`excel2md (CSV)`、`excel2md (CSV+Mermaid)` が選択肢として含まれている |
| 2-3 | 変換ボタン押下で Markdown に変換される | AI | 「マークダウンに変換」ボタン押下後、ボタン下のステータス表示が「変換済み」になる。「変換結果をプレビュー」をクリックすると、灰色のプレビューエリアに Markdown テキストが表示される |
| 2-4 | 変換結果にファイル名の見出しが含まれる | AI | プレビューエリアのテキスト内に `# 設計書: {ファイル名}` 形式の見出しが含まれている |

## シナリオ3: プログラムの変換

### 手順

> テスト準備で Java ファイルが選択済みであること。

1. プログラムのファイル名が表示されていることを確認する
2. 「add-line-numbersで変換」ボタン（青色）をクリックする
3. 変換完了後、「変換結果をプレビュー」をクリックして変換内容を確認する

### 試験項目

| # | 試験項目 | 実行 | 判定基準 |
|---|---------|:----:|---------|
| 3-1 | コードファイルが選択されている | AI | テスト準備で選択した Java ファイルのファイル名が「プログラム」セクションに表示されている |
| 3-2 | 変換ボタン押下で行番号が付与される | AI | 「add-line-numbersで変換」ボタン押下後、ステータスが「変換済み」になる。「変換結果をプレビュー」をクリックすると、プレビューエリアに `   1: ` 形式の行番号付きコードが表示される |
| 3-3 | 変換結果にファイル名の見出しが含まれる | AI | プレビューエリアのテキスト内に `# プログラム: {ファイル名}` 形式の見出しが含まれている |

## シナリオ4: レビュー実行（分割モード）

### 手順

1. シナリオ2・3が完了し、設計書とプログラムの両方が「変換済み」の状態であることを確認する
2. 「分割設定」セクションで「分割」ラジオボタンを選択する
3. 「分割オプション」をクリックして展開し、設計書の分割モードで「AI（推奨）」ラジオボタンを選択する
4. 「分割プレビュー」ボタン（青色）をクリックし、プレビュー結果が表示されるまで待つ
5. 画面下部の「レビュー実行」ボタン（緑色）をクリックする
6. 「分割レビュー実行中」画面に遷移し、以下のステップが順番に実行される:
   - **1. 構造マッチング**: 設計書とプログラムの対応関係を分析
   - **2. グループレビュー**: 各グループごとにAIがレビューを実行（エラー時は「リトライ」で再試行、同じエラーが続く場合は「スキップ」で次へ）
   - **3. 結果統合**: 各グループの結果を統合
7. 完了後、自動的に結果画面に遷移する

### 試験項目

| # | 試験項目 | 実行 | 判定基準 |
|---|---------|:----:|---------|
| 4-1 | レビュー実行ボタンが有効になっている | AI | 設計書・プログラム両方が変換済みかつ分割プレビュー完了の状態で、「レビュー実行」ボタン（緑色）が押下可能（disabled でない）になっている |
| 4-2 | レビュー実行中にローディング表示される | AI | 「レビュー実行」ボタン押下後、「分割レビュー実行中」画面に遷移し、「1. 構造マッチング」「2. グループレビュー」「3. 結果統合」の進捗が表示される。実行中のステップにはスピナーアイコンが表示される |
| 4-3 | レビューレポートが表示される | AI | 全ステップ完了後、「分割レビュー結果」画面に遷移し、「詳細レポート」セクションに Markdown 形式のレビューレポートが表示される |
| 4-4 | 簡易判定が表示される | AI | 結果画面の「簡易判定」セクションに、「問題あり」（赤）/「確認が必要」（黄）/「問題なし」（緑）のいずれかのステータスアイコンとラベルが表示される |
| 4-5 | レビュー情報が表示される | AI | 結果画面の「実行情報」セクションに「バージョン」「モデルID」「実行日時」「トークン数:（入力 X / 出力 X）」「レビューモード: 分割」が表示される |

## シナリオ5: レビュー結果のダウンロード

### 手順

1. シナリオ4が完了し、結果画面が表示されている状態であることを確認する
2. 「詳細レポート」セクションの各ボタンを操作する
3. 「レビュー実行データ一式ダウンロード」セクションでZIPをダウンロードする

### 試験項目

| # | 試験項目 | 実行 | 判定基準 |
|---|---------|:----:|---------|
| 5-1 | レポートのコピーボタンが機能する | AI | 「詳細レポート」セクションの「コピー」ボタン（クリップボードアイコン付き、灰色）を押下し、クリップボードにレポートテキストがコピーされる |
| 5-2 | レポートの MD ダウンロード | AI | 「詳細レポート」セクションの「ダウンロード」ボタン（青色）を押下し、`.md` ファイルがダウンロードされる |
| 5-3 | ダウンロードした MD にレポートヘッダが含まれる | AI | ダウンロードした MD ファイルに「設計書-Javaプログラム突合 AIレビュアー レビューレポート」というタイトルと、実行情報テーブル（バージョン、モデルID、実行日時、トークン数）が含まれている |
| 5-4 | 一式ダウンロード（ZIP） | AI | 「レビュー実行データ一式ダウンロード」セクションの「一式ダウンロード（ZIP）」ボタン（緑色）を押下し、ZIP ファイルがダウンロードされる |
| 5-5 | ZIP の内容確認 | AI | ダウンロードした ZIP を展開し、以下の5ファイルが含まれている: `README.md`, `system-prompt.md`, `spec-markdown.md`, `code-numbered.txt`, `review-result.md` |
| 5-6 | ZIP の README 確認 | AI | `README.md` にレビュー情報（バージョン、モデルID、実行日時、トークン数）と同梱ファイル一覧（5ファイルの説明）が記載されている |

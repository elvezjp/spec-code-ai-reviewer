# v0.9.0 アップグレード計画

- 作成日: 2026/02/28
- ステータス: 計画中

## 背景

PR #48（分割レビュー品質改善）およびPR #50（要約・エラー表示改善）で、`versions/v0.8.2` に対して多数の変更が加えられている。しかし、v0.8.2 は main ブランチの状態のまま保持し、これらの改善を新バージョン **v0.9.0** としてリリースする方針に変更する。

### PR #48 の変更内容（分割レビュー品質改善）

- 構造マッチングの output_format をIDのみに簡素化、グルーピング精度向上
- 分割プレビューに「重要」チェックボックス追加、全グループで共通参照
- グループレビュー・統合レビューに全体構造情報を渡し、未実装の誤指摘を防止
- 環境変数 `MD2MAP_MAX_SUBSECTIONS` でサブスプリット上限を制御可能に
- 対応なしグループのレビュー自動スキップ、表示修正

### PR #50 の変更内容（要約・エラー表示改善）

- 要約APIの分離（`summarize.py` 新設）
- 事前要約機能の実装（重要セクションの要約によるトークン削減）
- 一括レビュー時・Markdown整理時のエラー表示改善
- リトライ設定パネル追加
- リトライ表示条件の修正

### 未実装の計画書（本バージョンに含める）

- `20260228-organize-markdown-token-limit-removal-plan.md`: Markdown整理のトークン上限チェック廃止
- `20260228-pinned-part-summarize-plan.md`: 重要セクションの事前要約機能
- `20260225-prompt-caching-plan.md`: プロンプトキャッシング（計画書のみ、実装は次バージョン以降）

## 実装手順

### Step 1. v0.9.0 ディレクトリを作成

現在のブランチの v0.8.2（PR #48・#50 の変更済み状態）を v0.9.0 としてコピーする。

```bash
# 現在のブランチの v0.8.2（変更済み）を v0.9.0 としてコピー
cp -r versions/v0.8.2 versions/v0.9.0
```

### Step 2. v0.8.2 を main ブランチの状態に戻す

PR #48、#50 の変更を v0.8.2 から除外し、main ブランチの状態に戻す。

```bash
# main ブランチの v0.8.2 を復元
git checkout main -- versions/v0.8.2/
```

### Step 3. v0.9.0 のバージョン番号を更新

#### 3-a. バックエンド: `pyproject.toml`

```toml
# versions/v0.9.0/backend/pyproject.toml
[project]
name = "spec-code-ai-reviewer-backend"
version = "0.9.0"
```

#### 3-b. フロントエンド: `package.json`

```json
{
  "name": "frontend",
  "version": "0.9.0"
}
```

### Step 4. インフラ設定ファイルの更新

v0.9.0 のポート番号は、ポート規則 `8000 + (minor × 10) + patch` に従い **8090** となる。

#### 4-a. `ecosystem.config.js`

VERSIONS 配列の先頭に追加:

```javascript
{ name: 'spec-code-ai-reviewer-v0.9.0', cwd: 'versions/v0.9.0', port: 8090, workers: 1 },
```

#### 4-b. `dev.ecosystem.config.js`

同様に VERSIONS 配列の先頭に追加:

```javascript
{ name: 'spec-code-ai-reviewer-v0.9.0', cwd: 'versions/v0.9.0', port: 8090, workers: 1 },
```

#### 4-c. `nginx/version-map.conf`

```conf
# バックエンドポートマップに追加
"v0.9.0"  8090;

# defaultを v0.9.0 に変更
default   8090;  # latest (v0.9.0)

# フロントエンドルートマップに追加
"v0.9.0"  /var/www/spec-code-ai-reviewer/versions/v0.9.0/frontend;

# defaultを v0.9.0 に変更
default   /var/www/spec-code-ai-reviewer/versions/v0.9.0/frontend;  # latest (v0.9.0)
```

#### 4-d. `docker-compose.yml`

```yaml
# nginx volumes に追加
- ./versions/v0.9.0/frontend/dist:/var/www/spec-code-ai-reviewer/versions/v0.9.0/frontend:ro

# backend expose に追加
- "8090"
```

### Step 5. シンボリックリンクの更新

```bash
rm latest && ln -s versions/v0.9.0 latest
```


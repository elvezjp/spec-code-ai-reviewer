# v0.9.9 対応計画書（Python 3.11 への要件引き上げ）

- 対応 Issue: [#104](https://github.com/elvezjp/spec-code-ai-reviewer/issues/104)
- Dependabot alert: [#502](https://github.com/elvezjp/spec-code-ai-reviewer/security/dependabot/502)（`idna < 3.15`, GHSA-65pc-fj4g-8rjx）

## 概要

依存先（`add-line-numbers` / `md2map` / `code2map`）の最新 main が Python `>=3.11` を要求するため、`v0.9.8` のままでは `uv.lock` を再生成できず Dependabot アラートを解消できない。既存 `v*/` は凍結ルールのため、**`v0.9.9` を新設**して Python 3.11 へ引き上げる。

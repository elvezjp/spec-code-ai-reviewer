# シナリオテスト — spec-code-ai-reviewer

## 指示

以下のシナリオを順番に実行し、試験項目ごとに OK / NG を判定してください。
結果は `tests/results/YYYYMMDD-HHMM-scenario.md` に報告してください。

- 結果報告の冒頭にサマリー（OK数 / NG数 / MANUAL数 / 総数、NG項目の一覧）を出力すること
- MANUAL の項目はスキップし、結果に MANUAL と記載すること
- NG の場合は、エラー内容や実際の出力を備考に記載すること
- 各シナリオの手順に従い、試験項目の判定基準で合否を判断すること
- Python の実行は uv を使うこと
- Node.js の実行は npm を使うこと

## シナリオ1: バックエンドのセットアップ

### 手順

1. `versions/v0.9.0/backend` に移動する
2. `uv sync --all-extras` で依存関係をインストールする
3. `uv run pytest` で単体テストを実行する

### 試験項目

| # | 試験項目 | 実行 | 判定基準 |
|---|---------|:----:|---------|
| 1-1 | `uv sync --all-extras` が成功する | AI | 終了コード 0、エラーなし |
| 1-2 | `uv run pytest` が全件パスする | AI | 終了コード 0、失敗テストなし |

## シナリオ2: フロントエンドのセットアップ

### 手順

1. `versions/v0.9.0/frontend` に移動する
2. `npm ci` で依存関係をインストールする
3. `npm run test:run` で単体テストを実行する
4. `npm run build` でビルドを実行する

### 試験項目

| # | 試験項目 | 実行 | 判定基準 |
|---|---------|:----:|---------|
| 2-1 | `npm ci` が成功する | AI | 終了コード 0、エラーなし |
| 2-2 | `npm run test:run` が全件パスする | AI | 終了コード 0、失敗テストなし |
| 2-3 | `npm run build` が成功する | AI | 終了コード 0、`dist/` が生成される |

## シナリオ3: バックエンドの起動確認

### 手順

1. `versions/v0.9.0/backend` に移動する
2. `uv run uvicorn app.main:app --port 8000` でサーバーを起動する
3. ヘルスチェックエンドポイントにアクセスする
4. サーバーを停止する

### 試験項目

| # | 試験項目 | 実行 | 判定基準 |
|---|---------|:----:|---------|
| 3-1 | サーバーが起動する | AI | `Uvicorn running on` のログが出力される |
| 3-2 | `/docs` にアクセスできる | AI | HTTP 200 が返る（FastAPI の自動生成ドキュメント） |

## シナリオ4: API エンドポイントの疎通

### 手順

1. バックエンドサーバーが起動している状態で、主要な API エンドポイントに対してリクエストを送信する
2. レスポンスのステータスコードとレスポンス形式を確認する

### 試験項目

| # | 試験項目 | 実行 | 判定基準 |
|---|---------|:----:|---------|
| 4-1 | 変換 API にファイルなしでリクエスト | AI | HTTP 422（バリデーションエラー）が返る |
| 4-2 | 分割 API にファイルなしでリクエスト | AI | HTTP 422（バリデーションエラー）が返る |

3. ブラウザでアクセスできることを確認する
